# Changelog

The npm package and the Figma file share version numbers.

## Unreleased

## 1.1.0 (17 October 2026)

The first public release, on npm, GitHub and the [Figma Community](https://www.figma.com/community/file/1691663776222213480/evenkeel-design-system).

- All the examples now follow one story: Lantern Bikes, an online bike shop, in the week it moves its payments to Mintline. The same people, numbers and dates appear in every template, demo and flow.
- A mobile app kit in Figma: phone components, 16 screens and three phone flows. It's Figma only for now.
- AI components, patterns and page templates, where an agent always asks before it acts.
- Views templates (transactions, disputes) in Storybook, plus products and schedule views in Figma.
- Every Figma component's description shows how to use it in code.
- Simpler docs.

## 1.0.0 (4 October 2026)

The first version: tokens and four themes in light and dark, two densities, 48 components, charts, data views, icons, illustrations, patterns, page templates and user flows, in Figma and React.
