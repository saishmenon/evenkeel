## Description (≈150 words)

```
Evenkeel is a free, open-source design system for the screens people stare at all day: dashboards, tables, logs, settings and billing.

It lives in Figma and React at the same time, with the same names in both. Every colour, space, radius and text size is a variable or style, so switching theme, light/dark or density is one click on a frame, and maps one-to-one to the code.

Four themes (Default, Graphite, Ember, Studio), each generated from five knobs and checked for WCAG AA contrast in light and dark. Two densities, comfortable and compact. 48 components with real variants, charts, data views, 500+ icons, illustrations, patterns, 20+ page templates and click-through user flows, all built for a fictional payments platform called Mintline.

Code (MIT): github.com/saishmenon/evenkeel · npm i evenkeel-ui
This file is published under CC BY 4.0, as all Community files are.
```

## What's inside

```
• Variables: Theme (4 modes), Color (Light/Dark), Density (Comfortable/Compact), Size, Motion, Palettes
• 15 text styles and 3 elevation styles that match the CSS one-to-one
• 48 components with variants and the same usage guidance as the code docs
• An AI section: 31 AI components, 9 patterns and 7 templates where agents ask before they act
• A mobile app kit: phone foundations, components and 16 app screens
• Charts: bar, line, area, stacked, donut, bar list, sparkline, gauge, heatmap
• Data views: table, list, grid, board, calendar, timeline, split
• Colour palettes: 13-hue spectrum, greys, categorical, sequential and diverging data-viz palettes
• 500+ icons on a 24px grid, including a curated Lucide set
• Illustrations for empty states and onboarding
• Patterns: payments list, details, create flow, dashboard, empty states
• 20+ templates and 12 user flows that tell one story: a week at an online bike shop that has just moved to Mintline
• Brand guide: logo (mark + lockup), colour, type, motif and voice
• 12 marketing templates with editable text: social posts, banners, Open Graph, GitHub preview, Community cover, slides, release card, email header (paste into Figma Buzz to use as Buzz templates)
• Every colour bound to a variable: themes and dark mode just work
```

## Cover image spec

| | |
|---|---|
| Size | **1920 × 960 px** (2:1), PNG or JPG, under 5 MB |
| Safe area | Keep the wordmark, tagline and key visuals inside the centre **1600 × 800**; edges crop in small gallery cards |
| Content | Wordmark "Evenkeel", tagline "Calm interfaces for dense data.", and a dashboard shown in two or three themes (one light, one dark) |
| Text | At most ~8 words; must be readable at 25% scale |
| Background | Solid or subtle gradient from the theme neutrals; avoid pure white (blends into the gallery) |
| Source | Figma › Cover page, frame `Community cover` |
